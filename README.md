Лабораторна робота №9: Геолокація + Кеш (offline)

Опис проекту
Цей Android-додаток реалізує функціонал отримання поточної геолокації пристрою, її збереження в локальну базу даних (Room) та відображення історії запитів. Додаток працює в режимі офлайн (відображає кешовані дані) та коректно обробляє дозволи (Runtime Permissions).

Функціонал
- Отримання поточних координат (Latitude, Longitude) та точності (Accuracy).
- Збереження кожної отриманої точки в базу даних з таймстемпом.
- Відображення списку всіх збережених локацій у зворотному хронологічному порядку.
- Можливість повної очистки кешу.
- Обробка запитів на дозволи та перенаправлення в налаштування при відмові.

Архітектура
Проект побудований на принципах **Clean Architecture** та паттерні **MVVM**:
- UI (Compose): Відображає стан, отриманий від ViewModel.
- ViewModel: Керує станом екрану та бізнес-логікою.
- Repository: Єдина точка доступу до даних (FusedLocationProvider та Room DAO).
- Room Database: Виступає як **Single Source of Truth (SSOT)** - UI оновлюється автоматично при зміні даних у БД.

Як запустити
1. Клонуйте репозиторій.
2. Відкрийте проект в Android Studio.
3. Переконайтеся, що на пристрої/емуляторі встановлені Google Play Services.
4. Запустіть додаток на пристрої (Run 'app').
5. При першому запуску надайте дозвіл на доступ до геолокації.
